Solmar Bay — an open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty: a sun-soaked city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted level with pursuing police, five story missions, taxi fares, combat, shops, a HUD with a minimap, synthesized sound and saves. Runs offline in a desktop browser from static files, no network requests.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
